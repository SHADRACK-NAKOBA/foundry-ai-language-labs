## LinkedIn post template

> **I built three language AI capabilities on Microsoft Foundry: analyze, reason, speak.**
>
> **1 · Text analytics with privacy built in:** language detection, entity extraction and **PII redaction** on hotel reviews with Azure Language, before anything is stored.
>
> **2 · An agent that picks its own NLP tools:** a Foundry agent connected to the **Azure Language MCP server** decides whether a request needs entities, sentiment or redaction, and calls the right tool.
>
> **3 · Voice in and out:** text-to-speech with **gpt-4o-mini-tts** (voice + tone control) and speech-to-text with **gpt-4o-mini-transcribe**.
>
> All in Python, keyless with Entra ID.
>
> **Lesson:** combine specialized AI services with LLM reasoning; don't make one model do everything.
